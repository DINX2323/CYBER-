How to read this experiment

The selected placement maximizes training detection rate − training false-positive rate over all 15 pairs of six candidate locations. It is frozen before evaluation on the held-out routes. Both sets come from the same synthetic route generator.

A detection occurs when an intrusion route touches a decoy location. A false alert occurs when an ordinary route does the same. “Steps to detection” is the average position of the first decoy among detected intrusion routes only. Lower is earlier.

The random baseline uses one seeded pair. A publishable evaluation should add repeated seeds, confidence intervals, richer legitimate workloads, and separately collected test data. Placement learning here is an exhaustive search, not an AI model.
